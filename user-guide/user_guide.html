pgn-extract GUI Documentation

Introduction

Overview

This tool is a GUI for pgn-extract A tool that is used to extract chess games from PGN files using filters and options which aims to improve the user experience by providing a graphical interface for the command-line tool and streamlining the usage of its features.

Requirements

The GUI requires the following:

  • Python3
  • PyQt6 installed
  • pgn-extract installed on your system in the same directory as the GUI.
  • (Windows & maxOS only) A compatible operating system
  • (macOS only) Command Line Tools

Installation

Install the GUI application here: click here.

If you already have a version of pgn-extract installed, move it to the same working directory as the GUI.

Otherwise, after installation, open the GUI app and go to the settings tab press to install pgn-extract

If not booting from a windows machine, you will need to open the terminal and navigate to the directory containing the GUI. and install the requirments as so. 

cd extracted/directory/of/pgn-extract
pip install -r requirements.txt

Once the requirements are installed, you can run the GUI by executing the following command:

python main.py

OSX and Linux

Installation of pgn-extract differs and can be manually installed or using the in-built installer in the GUI. (Can be unreliable.)

Please download the latest version here and follow the steps in a terminal

unzip pgn-extract-25-01.zip
        
cd extracted/directory/of/pgn-extract

        
make

        
sudo ln -s "$PWD/pgn-extract" /usr/loca/bin/pgn-extract
